# 0003 — Precificação em ≤3 pacotes de resultado + porta avulsa + bundle

Status: aceita

## Contexto
O CEO rejeitou lista de add-ons técnicos inchada (decisão registrada). PME compra resultado, não tecnologia.

## Decisão
Ofertas agrupadas em até 3 pacotes com nomes de resultado (ex.: "Aparecer no Google PRO"), mais porta avulsa e bundle com desconto. Validação de portfólio via Conselho 5/5.

## Consequências
+ Oferta compreensível para PME; ticket recorrente claro.
− Serviços técnicos precisam caber nos pacotes (sem cauda longa de SKUs). Nomes canônicos completos a confirmar com CEO.
