# 0004 — Tier premium: mecânica-assinatura interativa + assinatura estética passiva

Status: aceita

## Contexto
Sites premium precisam se diferenciar visivelmente do tier base para justificar preço, sem virar "AI slop".

## Decisão
Todo site premium tem uma mecânica-assinatura (elemento interativo exclusivo) e uma assinatura estética (elemento visual passivo recorrente que NUNCA cruza texto — regra do CEO). Qualidade ancorada na taste library (referências premiadas reais).

## Consequências
+ Diferenciação clara e vendável por tier; padrão de qualidade auditável.
− Cada premium exige design individual (não templável 100%).
